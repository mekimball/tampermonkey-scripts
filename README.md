# Tampermonkey Userscripts

A collection of custom browser scripts for tabletop tools and web enhancements.

## Available Scripts

| Script | Description | Install Link |
| :--- | :--- | :--- |
| **D&D 2024 Background Finder** | Interactive modal on D&D Beyond to filter 2024 backgrounds by stats, origin feats, and keywords. | [📥 Install Script](https://raw.githubusercontent.com/mekimball/tampermonkey-scripts/main/dnd-background-finder/dnd-background-finder.user.js) |
| **D&D Beyond Inline Materials** | Traverses React state to inject spell material costs and consumption badges into spell lists. | [📥 Install Script](https://raw.githubusercontent.com/mekimball/tampermonkey-scripts/main/dnd-inline-materials/dnd-inline-materials.user.js) |
| **D&D Beyond Spell Quick-Info** | Injects casting time, range, and components directly into collapsed spell header lines. | [📥 Install Script](https://raw.githubusercontent.com/mekimball/tampermonkey-scripts/main/dnd-spell-quick-info/dnd-spell-quick-info.user.js) |
| **DDB Book Downloader** | Fetches and compiles full D&D Beyond sourcebook chapters into a print/PDF-ready page. | [📥 Install Script](https://raw.githubusercontent.com/mekimball/tampermonkey-scripts/main/ddb-book-downloader/ddb-book-downloader.user.js) |

## Installation Instructions

1. Install the [Tampermonkey extension](https://www.tampermonkey.net/) for your browser.
2. Click any **Install Script** link in the table above.
3. Tampermonkey will open an installation tab. Click **Install**.
4. The scripts will automatically stay updated whenever changes are pushed to this repository.
